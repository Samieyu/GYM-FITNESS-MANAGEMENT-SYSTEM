# GYM-FITNESS-MANAGEMENT-SYSTEM

Technology stack
- Frontend: React.js
- Backend: Node.js + Express.js
- Database: PostgreSQL
- Database driver: pg
- Mobile app: Flutter (dart)
- AI: LLM API (Gemini API)
- Deployment: Oracle Cloud Infrastructure (OCI)

1. Introduction
1.1 Purpose
This document lists what the Gym & Fitness Management System shall do. It covers online registration, memberships and payments, QR check-in, trainer workout plans, progress tracking, classes and bookings, notifications, equipment maintenance, and AI assistance.
